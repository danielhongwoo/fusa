# 2차: 반영 결과와 확인 요청

1차 검토 두 개 (`round1-fusa.md`, `round1-embedded.md`)를 진행자 (Claude 주 세션)가 반영했다. 두 검토자는 반영이 지적을 풀었는지 답한다.

1차의 결과
- 두 검토자 모두 조건부 통과였다. 반드시 고칠 것 (A)이 각각 넷이었다.
- 두 검토의 지적은 서로 부딪치지 않았다. E-03과 F-02, E-04와 F-16, E-11과 F-14는 같은 곳을 가리켰다.
- 진행자는 A 여덟 개를 모두 받아들였다. B는 아래 표의 두 개를 빼고 반영했다.

반영한 commit: `2343221` (코드와 test), `ea3f8f1` (예제 문서), `eb5b29f` (장, 용어집, 근거 기록).

## A 지적

| 지적 | 반영한 것 | 검토자가 권한 것과 다른 점 |
|---|---|---|
| F-01 감시의 허용 토크가 `SG-01`에서 나오지 않았다 | `TSR-03`과 `SWR-06`에 두 방향의 조건을 적었다: 정상인 기능의 토크 요구는 허용 토크를 넘지 않고, 둘의 차이는 55 Nm보다 작다. 기능에서 속도에 따른 감소와 "속도를 모르면 절반"을 뺐다. technical-safety-concept.md 3절에 "허용 토크와 정상 동작 사이의 틈"을 더했다. FTA에 E10, safety case에 G9를 더했다. test: `TC-007` (두 방향), `TC-011` (올리는 동안의 시간), `TC-204` (`FI-06`, 후진). 7, 10, 11, 12장에 원칙과 예제의 실제 사례를 적었다 | 후진의 비율은 기능에서 빼지 않고 감시에도 넣었다 (기어는 이미 감시의 입력이다). 변화율은 기능이 올리는 속도를 주기마다 25 Nm로 높여, 차이가 55 Nm 이상인 시간을 70 ms로 줄였다. 감시가 변화율을 보게 하지는 않았다. 기능이 속도를 쓰지 않게 되어 VCU는 차량 속도를 읽지 않는다. 높은 속도의 fault injection은 그래서 더하지 않았다 |
| F-02 safety case가 근거보다 많이 주장한다 | G1에 "단계 1에서는 아직 성립하지 않는다"를 달았다. G7 (브레이크와 기어의 입력), G8 (전송)을 근거 없는 주장으로 그렸다. 머리와 19장에 열린 가지 넷을 모두 적었다. G4를 "50 ms 안에 토크 0을 보내고 구동 허용 신호를 끊는다"로 고치고, 모터의 토크가 내려가는 것은 108 ms 뒤이며 가정에 기댄다고 적었다 | 없다 |
| F-03 브레이크와 기어 입력의 고장 | functional-safety-concept.md 6절, technical-safety-concept.md 6절, hara.md 6절, fta.md E4와 E5, 11장의 "약한 곳" 표, 12장의 표에 적었다 | 없다. 검사 자체는 단계 2로 두었다 |
| F-04 시간의 끝점 | 6장, 7장, 부록 A를 "위험한 상태가 되기 전까지. 사고는 그 뒤에 온다"로 맞췄다 | 없다 |
| E-01 차량 수준의 판정이 감시 없이도 통과한다 | `FI-02`의 fault를 100 Nm로 키웠다. 감시와 출력 단계를 아무것도 하지 않는 모듈로 바꿔 끼운 대조 test (`NC-001`)를 더했다: 같은 fault에서 가속의 차이 1.81 m/s^2, 984 ms. test-report, 12, 16, 19장에 적었다 | 대조를 변이 검사가 아니라 모듈을 바꿔 끼운 test로 만들었다. `make test`에서 늘 돈다 |

| E-03 G2의 문장이 근거보다 세다 | G2를 "두 채널이 함께 틀리지 않는 한 ..."으로 고치고 가정 (`A-02`, `A-12`)을 그림에 붙였다. 표에 "근거가 보이는 것은 작은 쪽을 낸다까지"라고 적었다. 19장의 그림과 글도 고쳤다 | 주장을 둘로 나누지 않고, 조건을 주장의 문장에 넣었다 |
| E-04 test-report가 자동으로 만들어지지 않는다 | 16장과 test-report.md 머리에 "결과를 옮겨 적은 문서"라고 적고, 숫자를 다시 옮겼다 | coverage 표를 자동으로 만드는 것은 하지 않았다 |

## 확인 요청

1. 자기가 낸 A 지적이 풀렸는가. 지적마다 "풀림" 또는 "안 풀림"과 이유.
2. 상대가 낸 A 지적의 반영 가운데 틀렸거나 새 문제를 만든 것이 있는가.
3. F-01의 반영에서 "검토자가 권한 것과 다른 점" (후진의 비율을 감시에 넣음, 올리는 속도를 높임, 속도를 읽지 않음)에 동의하는가.
4. 판정: 통과 / 조건부 통과 / 불가.

합의되지 않는 것은 3차에서 한 번 더 다루고, 그래도 남으면 진행자의 안으로 진행한 뒤 저자에게 쟁점으로 알린다.
