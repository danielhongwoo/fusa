# 2차: 반영 결과와 확인 요청 (단계 2의 묶음 1: 1, 4, 5장)

1차 검토 두 개 (`round1-fusa.md`, `round1-embedded.md`)를 진행자 (Claude 주 세션)가 반영했다. 두 검토자는 반영이 지적을 풀었는지 답한다.

1차의 결과
- 두 검토자 모두 조건부 통과였다. 반드시 고칠 것 (A)은 FuSa 둘, 임베디드 넷이었다.
- 두 검토의 지적은 서로 부딪치지 않았다. F-18과 E-09 (development interface agreement), F-07과 E-10 (독립의 세 가지가 NASA의 틀)은 같은 곳을 가리켰다.
- 진행자는 A 여섯을 모두 받아들였고, 지적마다 근거 문서의 쪽을 직접 읽어 확인한 뒤 고쳤다.

반영한 commit: `eb76feb` (FuSa의 지적), `db4ab06` (임베디드의 지적).

## A 지적

| 지적 | 반영한 것 |
|---|---|
| F-01 코드의 결함을 세는 문장이 근거와 어긋난다 | 셈을 뺐다. "어느 사례도 코드의 결함만으로는 설명되지 않는다"로 고쳤다 (머리, 흔한 오해). Therac의 교훈에 "사고에 원인 하나를 붙이는 것은 대개 심각한 잘못"을 더했다 (Leveson과 Turner 18쪽). 737 절에 AOA DISAGREE 경고의 소프트웨어가 인증받은 설계와 달랐다는 것을 더했다 (KNKT 180쪽, 217쪽). "가져갈 것"을 "구현이 설계와 달랐던 것은 경고 하나였고 ... 사고의 중심은 설계와 그 위의 판단"으로 고쳤다 |
| F-02 assessment의 뜻이 4장과 5장에서 다르다 | 4장의 표를 네 줄로 나눴다: 따랐다, 평가받았다 (무엇을 평가했는지를 묻는다), 인증서를 받았다, 승인받았다. 5장의 표에 audit과 functional safety assessment가 다른 일이라고 적었다. 용어집의 두 항목을 "compliance, 인증서, 승인"과 "verification, validation, audit, functional safety assessment"로 다시 썼다 |
| E-01 "코드는 한 글자도 바뀌지 않았다" | "조사 위원회는 두 장치의 설계, 특히 소프트웨어가 거의 같다고 적는다"로 고쳤다 |
| E-02 "다시 쓴다"가 재작성으로 읽힌다 | 1장과 5장의 모든 곳을 "재사용"으로 고쳤다. Therac의 교훈에 "다른 기계에서 잘 돌던 모듈이라는 것은 이 기계에서 안전하다는 근거가 아니다"를 더했다 |
| E-03 Ariane 권고의 문장 | "틀렸다고 드러나기 전까지는 옳다고 보는 시각을 버리고, 지금 알려진 가장 좋은 방법으로 옳다고 보일 때까지는 틀렸다고 가정하라"로 고쳤다 |
| E-04 4장의 근거 없는 문장 둘 | (a)는 "등급의 이름과 정하는 방법부터 다르다 (3장)"만 남겼다. (b)는 Part의 제목에서 읽을 수 있는 것만 적었다 (Part 3은 concept phase, 4는 시스템 수준, 9는 분석, 8은 지원 과정) |

## 반영하지 않았거나 다르게 한 것

1. E-13 (분량). 4장은 표를 옮겨 줄었다. 1장은 줄이지 않았고, "코드의 눈으로 보면"과 NASA가 찾은 것을 더해 더 길어졌다. 상한 (12쪽)을 넘는다. 이유: 다툼이 있는 사례에서 누가 무엇을 말했는지를 나눠 적는 데 드는 길이다. 줄일 곳에 대한 의견을 묻는다 (확인 요청 3).
2. F-06의 그림. "검증과 확인"을 "verification과 validation"으로 바꿨을 뿐 상자를 둘로 나누지 않았다.

## 확인 요청

1. 자기가 낸 A 지적이 풀렸는가. 지적마다 "풀림" 또는 "안 풀림"과 이유.
2. 반영이 새 문제를 만들었는가. 특히 새로 더한 것: 1장의 "코드의 눈으로 보면" 표 (C의 정의되지 않은 동작, watchdog에 관한 줄), 4장의 "규격을 처음 받았을 때"와 네 줄로 나눈 표, 5장의 validation 줄과 "엔지니어의 일로 옮기면" 표.
3. 1장이 상한을 넘는 것을 그대로 둘 것인가, 줄인다면 어디인가.
4. 판정: 통과 / 조건부 통과 / 불가.

합의되지 않는 것은 3차에서 한 번 더 다루고, 그래도 남으면 진행자의 안으로 진행한 뒤 저자에게 쟁점으로 알린다.
