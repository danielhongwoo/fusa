- 쓴 사람: 진행 (Claude 주 세션). 날짜: 2026-11-23.
- 1차의 지적: FuSa 11개 (A 1, B 4, C 6), 임베디드 8개 (A 1, B 2, C 5). 두 검토자 모두 조건부 통과였다. 임베디드 검토자는 묶음 3의 2차 지적 (E-11 - E-15)이 모두 닫혔다고 확인했다.

| F-01 16장의 "충분히 test했다"의 뜻 | A | 받아들였다. 물음을 넷으로 했다 (넷째: test가 내보내는 것, 곧 target의 build와 하드웨어에 대해 말하는가). 결론을 "네 물음에 답했고, 답이 아니다인 곳마다 그것을 맡는 다른 수단이나 받아들이는 까닭을 적었다"로 고치고, 적어 두기만 한 빈 곳은 충분하다는 근거가 아니라고 적었다. 예제의 표에 넷째 줄을 더했다 (답: 아니다). 초고의 정의와 지적받은 경위도 적었다 |

## 임베디드 엔지니어의 지적

| 지적 | 등급 | 한 일 |
|---|---|---|
| E-01 `make check`가 coverage가 100%에 못 미쳐도 실패하지 않는다 | A | 받아들였다. `tools/coverage.sh`가 요약 도구의 종료 상태를 넘기게 고쳤다. 16장의 문장 ("100%가 아니면 실패한다")은 진행자가 F-01을 고치다가 넣은 것이고 그때는 사실이 아니었다. 그 문장은 뺐다. `make step-check`가 닿지 않는 문장을 넣어 coverage 단계가 실패하는지를 본다 |
| E-02 "여덟 가운데 넷은 검토자가"가 표와 맞지 않는다 | B | 받아들였다. tools.md 3절의 표에 "찾은 쪽" 칸을 두고 줄을 열셋으로 넓혔다. 만든 쪽이 스스로 찾은 것 넷, 검토자 일곱, 원고를 쓰던 에이전트 하나, 도구 자신 하나. 17장의 문단도 그 수로 다시 썼다 |
| E-03 초기화를 빠뜨려도 아무것도 알리지 않는다 | B | 받아들였다. 상태를 쓰레기 값 두 가지 (0이 아닌 값과 0)로 채운 뒤에 init을 부르고 모든 필드를 값으로 보는 test를 넣었다 (`TC-023`, `TC-133`). 시나리오 실행기도 쓰레기 값에서 시작한다. 초기화를 빼는 변이 열넷을 목록에 넣었다. 0이 아닌 값만 넣은 첫 판은 "참으로 정해야 하는 필드" (켠 직후의 브레이크는 밟음)의 변이를 놓쳤다. tools.md 2절과 4절, 16장, 부록 A에 sanitizer가 초기화하지 않은 변수의 읽기를 알리지 않는다는 것을 적었다 |
| E-04 필요 없는 가정 넷 | C | 받아들였다. 넷을 모두 지웠고 세 성질이 그대로 증명된다 |
| E-05 clang-tidy가 아무 말 없이 죽으면 통과한다 | C | 받아들였다 (F-02와 함께) |
| E-06 GCC로 도는 test는 셋뿐이고 종료 상태만 본다 | C | 받아들였다. `make variants`에 GCC의 `-O0`과 `-O2`를 더했다. 일곱 실행 파일의 출력을 Apple clang의 `-O0`과 견준다. 한 줄도 다르지 않았다 |
| E-07 tools.md에 빠진 것 | C | 받아들였다. 빌드를 묶는 글을 도구로 넣었고 (1절, 2절), 4절에 target의 정수 폭과 memory 배치, 초기화하지 않은 변수를 보는 도구를 넣었다 |
| E-08 변형의 UBSan은 구조체 끝의 배열을 보지 않는다 | C | 받아들였다. `tools/variants.sh`의 머리 설명을 고쳤다 (배열 밖은 AddressSanitizer가 본다). option은 더하지 않았다 |

## 고치다가 찾은 것

- 변이 도구가 test가 끝나지 않는 변이를 300초 뒤에 끊을 때 `make`만 끝내고 그 아래의 test 실행 파일은 남겼다. 그렇게 남은 프로세스 하나가 한 시간 넘게 돌고 있었다. 지금은 프로세스의 묶음을 함께 끝낸다. `tools/step_check.py`도 같다.
- 변이 도구가 "잡음"을 어떻게 잡았는지로 가른다: 값의 검사가 실패를 찍은 것, 끝나지 않은 것, 실패를 찍지 않고 죽은 것. 뒤의 둘이 하나라도 있으면 도구가 실패한다.

## 진행자가 정한 것

- 도구가 없을 때 `make check`는 실패한다 (FuSa 검토자가 저자가 정할 것으로 올렸다). 돌리지 못한 검사가 있는데 통과했다고 말하지 않으려는 것이다.
- 16장의 Koopman 인용은 뺐다.
